# MGBS Task Bot

Discord-бот для публикации задач, откликов участников и проверки выполненной работы.

## Запуск локально

1. Установите Python 3.12 или новее.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и задайте `DISCORD_TOKEN`.
4. Запустите бота: `python -m app`.

## Запуск на хостинге

- Добавьте содержимое этой папки в отдельный Git-репозиторий.
- Установите переменную окружения `DISCORD_TOKEN` в настройках хостинга. Не добавляйте токен в Git.
- Команда запуска: `python -m app`.
- Если хостинг использует Dockerfile, он уже настроен на эту команду.
- Подключите постоянный диск к `/app/data` и задайте `DATA_DIR=/app/data`, чтобы база задач сохранялась после перезапуска.
- Для быстрой синхронизации команд с одним сервером задайте `DISCORD_TEST_GUILD_ID`; без неё команды синхронизируются глобально.

`TASK_BOT_DATABASE` можно задать как полный путь к файлу SQLite. Эта переменная имеет приоритет над `DATA_DIR`.

## Секреты

`.env` и база данных исключены из Git. Для локального запуска используйте `.env.example` как шаблон. Если токен уже отправлялся в чат или публиковался, сбросьте его в Discord Developer Portal и обновите переменную на хостинге.
